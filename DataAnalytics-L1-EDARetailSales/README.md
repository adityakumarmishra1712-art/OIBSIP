# Level 1 - Task 1: EDA on Retail Sales Data

## 📌 Project Objective
Perform a thorough Exploratory Data Analysis (EDA) on a retail sales dataset to uncover hidden patterns, customer behavior trends, and actionable business insights.

---

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Environment:** Jupyter Notebook

---

## 📋 Feature Checklist & Implementation

- [x] **Data Inspection & Cleaning:** Verified dataset dimensions (shape), column data types, and handled missing/null values.
- [x] **Descriptive Statistics:** Calculated mean, median, mode, and standard deviation for all numerical variables (sales, quantity, price).
- [x] **Time Series Analysis:** Plotted monthly and quarterly sales trends using line charts to identify seasonality and peak shopping periods.
- [x] **Customer Demographics Analysis:** Analyzed age group distributions and gender-wise purchasing patterns.
- [x] **Product Analysis:** Evaluated top 10 best-selling products and plotted total revenue by product category using bar charts.
- [x] **Correlation Heatmap:** Built a correlation matrix heatmap to analyze relationships between numerical variables.
- [x] **Additional Visualizations:** Plotted advanced distributions to uncover non-obvious buying patterns.
- [x] **Structured Markdown:** Documented written observations after each chart within the notebook.
- [x] **Actionable Business Recommendations:** Formulated strategic takeaways based on analytical findings.

---

## 💡 Key Business Recommendations
1. **Target Seasonal Peaks:** Ramp up inventory and targeted marketing campaigns prior to identified high-sales quarters.
2. **Prioritize High-Margin Categories:** Allocate dedicated promotional budgets to the top revenue-driving product categories.
3. **Personalized Demographic Campaigns:** Tailor special offers and loyalty discounts aligned with key customer age brackets and gender demographics.

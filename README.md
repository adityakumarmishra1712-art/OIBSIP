# Oasis Infobyte Internship (OIBSIP) - Data Analytics

This repository contains the completed tasks for the **Data Analytics Internship** at **Oasis Infobyte (OIBSIP)** under **Level 1**.

---

## 📌 Completed Tasks Overview

| Task | Title | Description | Folder Link |
| :--- | :--- | :--- | :--- |
| **Task 1** | **Exploratory Data Analysis (EDA) on Retail Sales** | Data cleaning, sales trend analysis, and demographic purchase patterns. | [View Task 1](./DataAnalytics-L1-EDARetailSales) |
| **Task 2** | **Customer Segmentation Analysis** | RFM feature extraction and K-Means clustering to identify high-value customer groups. | [View Task 2](./DataAnalytics-L1-CustomerSegmentation) |
| **Task 3** | **Data Cleaning** | Systematic data profiling, missing value imputation, type casting, and outlier management. | [View Task 3](./DataAnalytics-L1-CleaningData) |
| **Task 4** | **Sentiment Analysis** | NLP text preprocessing pipeline, TF-IDF vectorization, and multi-class sentiment classification. | [View Task 4](./DataAnalytics-L1-SentimentAnalysis) |
